# Portal público — Congreso Barrial Recoleta

Repositorio **separado** del análisis privado `germaquintana/congresobarrial`.

## Estado: solo estructura, sin resultados territoriales publicados

El archivo `index.html` contiene una interfaz estática con navegación para 24 unidades vecinales y diez dimensiones B01–B10. **No contiene las afirmaciones, testimonios, propuestas ni datos extraídos del repositorio privado.** Tampoco contiene documentos originales, IDs de fuentes privadas, datos personales, imágenes, mapas o enlaces a archivos de Drive.

La ausencia de contenido publicado **no significa** ausencia de menciones en las jornadas. Solo significa que el material todavía no está aprobado para difusión.

## Procedimiento antes de divulgar resultados
1. Revisar procedencia, vigencia y cotejo de fuentes por cada UV.
2. Validar semántica y exactitud de afirmaciones, distinguiendo problemas reportados, propuestas y acuerdos.
3. Examinar privacidad y riesgo de identificación indirecta, incluidos datos geográficos y grupos pequeños.
4. Obtener aprobación humana competente del paquete específico que se quiera difundir.
5. Exportar mediante lista blanca únicamente campos autorizados; evitar sincronización general desde el repositorio privado.
6. Habilitar Pages en **Settings → Pages** y verificar el sitio HTTPS real, únicamente cuando esté autorizado.

**No activar publicación automática de datos territoriales.**
