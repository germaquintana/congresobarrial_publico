Explorador multidimensional

Compara cómo se distribuyen las problemáticas, oportunidades, actores y lugares entre siete temáticas, quince subtemas y unidades vecinales. Selecciona una celda o barra para cruzar filtros y profundizar en los antecedentes.

Cómo leer este análisis: B03, B05, B06 y B07 son dimensiones del informe asociadas respectivamente a los tipos Problema, Oportunidad, Actor y Lugar importante. B01, B02, B04 y B08–B10 documentan contexto, instrumentos, cartografías y fuentes: no son clases independientes de cada registro, por lo que no se suman como si lo fueran. Los valores representan menciones registradas, nunca votos, delitos acreditados ni planes aprobados.

Lectura del conjunto seleccionado

1. Matriz de calor — temática × dimensión

Cada celda representa cuántos registros de una temática pertenecen a una dimensión operativa. Cambia entre valores absolutos y porcentaje dentro de cada temática. Haz clic en una celda para seleccionar temática y dimensión. La UV seleccionada se aplica a esta matriz.

2. Mapa de calor territorial — UV × temática

Permite comparar patrones entre UV. El filtro de dimensión modifica toda la matriz; el filtro de temática y la UV seleccionada quedan resaltados para conservar el contexto. En porcentaje, el denominador es el total de registros de la UV en la dimensión elegida (o todas si no hay dimensión).

3. Diagrama de flujos — temáticas hacia dimensiones

El ancho de los flujos representa la cantidad de registros (no relaciones causales). Los cuatro destinos son tipos excluyentes de un mismo registro, asociados a B03/B05/B06/B07. Selecciona un flujo para filtrar el panel. La visualización conserva los totales del universo territorial elegido.

Los caminos solo muestran cómo está clasificado el mismo conjunto de registros.

4. Perfil jerárquico — temáticas y subtemas

Los subtemas se vinculan a su temática por la tabla CAT_SUBTEMAS de la matriz madre. Este ranking responde a la UV y dimensión elegidas. Cuando una subcategoría concentra menos de tres registros en una única UV, se muestra como grupo pequeño para evitar una lectura excesivamente identificable.

5. Intersecciones para gestión municipal

Cruce UV × temática × dimensión y, si se elige, un subtema. Ordenado por número de registros. Selecciona «Examinar registros» para abrir el visor local con los filtros correspondientes: la página pública no incluye textos individuales.
